Политика на русском языке

1. Personal information

The game uses local player profiles, preferences, campaign progress and game statistics to provide its gameplay features.

2. Data storage and security

Local game data is stored on the user's device. Access to this data is governed by the operating system and its security settings. Users should protect access to their devices.

3. Microsoft Store and Xbox Live

Microsoft Store and Xbox Live (Xbox network) services may process Microsoft account information, account identifiers, licensing and authentication data when their services are used. Any account information accessed by the game through these services is used only to provide the relevant game functionality, not for advertising or resale.

Microsoft services are governed by the Microsoft Privacy Statement.

4. Webcam

The webcam is disabled by default. When enabled by the user and permitted by Windows, it displays a local live preview during gameplay. The game does not record, photograph or transmit webcam images or request microphone access for this feature.

5. Data sharing and third parties

Local gameplay data is not sold to third parties. Microsoft services, website hosting and email support providers may process information as necessary to provide their respective services.

6. User choices and data deletion

Users can access and edit their local profiles, delete profiles, reset campaign progress and disable the webcam. Camera permission can also be revoked through Windows privacy settings. Users may contact the publisher to request access to, correction or deletion of personal information held by the publisher.

7. Website and support

The website hosting provider may process technical request information for page delivery and security. When contacting support, the sender's email address and message are used to handle the request.

8. Contact

Privacy and support requests: put-shashista-support.pedometer144@simplelogin.com

9. Changes to this policy

This policy will be updated when relevant game features or data processing practices change.

Локальные игровые данные хранятся на устройстве пользователя. Доступ к ним регулируется средствами безопасности операционной системы. Пользователю следует защищать доступ к своему устройству.

4. Веб-камера

Камера отключена по умолчанию. При включении пользователем и наличии разрешения Windows изображение отображается локально во время игры. Игра не записывает, не фотографирует и не передаёт изображение с камеры, а также не запрашивает доступ к микрофону для этой функции.

Локальные игровые данные не продаются третьим лицам. Сервисы Microsoft, провайдер хостинга и почтовой поддержки могут обрабатывать сведения, необходимые для предоставления своих услуг.
